# Pixel-Art Tabby Cat Companion Implementation Plan

> **For Hermes:** Use the `subagent-driven-development` skill to implement this plan task-by-task, OR implement directly in order. Each task is bite-sized with exact paths, complete code, and verification.

**Goal:** Replace the existing cursor-chasing ASCII (kaomoji) cat with an autonomous, orange-tabby **pixel-art** cat that wanders the page on its own (no cursor following), cycles through multiple pixel animations (walk, sit/idle with blink + tail-flick, sleep, groom/lick, stretch, chase-tail), keeps the fading paw-print trail, and stays fully click-interactive.

**Architecture:** A single client component renders the cat as **inline SVG built from a pixel grid** (`shape-rendering: crispEdges`, one `<rect>` per opaque pixel) — asset-free, version-controlled, theme-independent (orange tabby color, not the muted gray). Movement and behavior are driven by a `requestAnimationFrame` loop using an **autonomous state machine**: the cat picks random wander targets anywhere on screen, lerps toward them, and transitions between behavior states on timers/RNG. All per-frame mutation happens through refs (no React re-render per frame); only discrete state/frame changes call `setState`. Pure helpers (wander-target picker, state chooser, frame selector) are extracted and unit-tested with vitest.

**Tech Stack:** Next.js 16 (App Router) + TypeScript, React 19 client component, inline SVG, CSS keyframes (existing `globals.css`), vitest (existing).

## Proposed approach (key design)

### Pixel sprite format

Each frame is an array of equal-length strings; each character is a palette key. A renderer maps keys → colors and emits `<rect width=1 height=1>` per opaque pixel inside an SVG `viewBox="0 0 W H"`, scaled up via CSS `width/height` with `shape-rendering: crispEdges` and `image-rendering: pixelated`.

**Palette keys** (orange tabby):

| Key | Meaning | Light/Dark color |
|-----|---------|------------------|
| `.` | transparent | — |
| `K` | outline / dark | `#3a2a1a` |
| `O` | orange body | `#e8943a` |
| `D` | dark-orange stripe | `#bd6a1e` |
| `W` | white belly/paws/muzzle | `#f5efe2` |
| `P` | pink nose/inner-ear | `#e58aa0` |
| `G` | eye (open) | `#5b8c3a` (green) |

Blink = swap `G`→`K` for that frame. Sleep eyes are drawn as a `K` line. Colors are constants in the component (NOT theme vars) because the cat is intentionally colored, per decision B. The grid is **16 wide × 16 tall**, cat drawn facing **right** (CSS `scaleX(-1)` flips it when moving left).

### Behavior state machine (autonomous, no cursor)

States: `walk`, `sit`, `idle` (sit + periodic blink/tail-flick), `sleep`, `groom`, `stretch`, `chase` (chase-tail spin), plus transient reaction states `happy` / `love` (click). The loop:

1. If currently moving toward a target and not yet arrived → state `walk`.
2. On arrival, pick a **dwell behavior** via weighted RNG (`sit`/`idle`/`groom`/`stretch`/`sleep`/`chase`) and hold it for a randomized dwell time.
3. After dwell, pick a **new random wander target anywhere on screen** (full viewport, minus a small margin so the sprite stays fully visible) and return to `walk`.
4. Click → enter `happy` or `love` for `REACTION_MS`, show a pixel-heart/`!` bubble, then resume.
5. `prefers-reduced-motion` → no wandering; just sit and occasionally blink.

No `mousemove` listener for movement (decision 6). We keep a click handler on the sprite only.

### Why extract pure helpers

`pickWanderTarget`, `pickDwellState`, and `frameForState` are deterministic given inputs (RNG injectable) → unit-testable without DOM, mirroring the existing `names.ts`/`relativeTime.ts` test pattern.

```typescript
// src/lib/catBehavior.ts
import type { CatState } from "./catSprites";

export type Point = { x: number; y: number };
export type Size = { w: number; h: number };

/**
 * Pick a random target anywhere on screen (full viewport) keeping the whole
 * sprite visible with an 8px margin. Cursor is intentionally NOT used.
 */
export function pickWanderTarget(
  vw: number,
  vh: number,
  size: Size,
  rand: () => number = Math.random
): Point {
  const maxX = Math.max(8, vw - size.w - 8);
  const maxY = Math.max(8, vh - size.h - 8);
  return {
    x: 8 + rand() * (maxX - 8),
    y: 8 + rand() * (maxY - 8),
  };
}

// Weighted dwell behaviors chosen when the cat arrives at a target.
const DWELL_WEIGHTS: ReadonlyArray<[Exclude<CatState, "walk" | "happy" | "love">, number]> = [
  ["sit", 3],
  ["idle", 4],
  ["groom", 3],
  ["stretch", 2],
  ["sleep", 2],
  ["chase", 1],
];

export function pickDwellState(
  rand: () => number = Math.random
): Exclude<CatState, "walk" | "happy" | "love"> {
  const total = DWELL_WEIGHTS.reduce((s, [, w]) => s + w, 0);
  let r = rand() * total;
  for (const [state, w] of DWELL_WEIGHTS) {
    if (r < w) return state;
    r -= w;
  }
  return "sit";
}

/** Randomized dwell duration (ms) per state. */
export function dwellDuration(
  state: CatState,
  rand: () => number = Math.random
): number {
  switch (state) {
    case "sleep":
      return 6000 + rand() * 6000;
    case "groom":
      return 2500 + rand() * 2500;
    case "chase":
      return 1500 + rand() * 1500;
    case "stretch":
      return 1200 + rand() * 800;
    default:
      return 2000 + rand() * 3000; // sit / idle
  }
}

/** Choose which frame index to show for an animated (multi-frame) state. */
export function frameForState(frameCount: number, tick: number): number {
  if (frameCount <= 1) return 0;
  return tick % frameCount;
}
```

```tsx
// src/components/PixelCat.tsx
"use client";
import { useMemo } from "react";
import {
  PALETTE,
  SPRITE_W,
  SPRITE_H,
  FRAMES,
  EYE_PIXELS,
  type CatState,
} from "@/lib/catSprites";

const SCALE = 4; // px per sprite pixel → 64x64 on screen

function Sprite({
  state,
  frame,
  blink,
  flip,
}: {
  state: CatState;
  frame: number;
  blink: boolean;
  flip: boolean;
}) {
  const grid = FRAMES[state][frame] ?? FRAMES[state][0];

  const rects = useMemo(() => {
    const eye = new Set(EYE_PIXELS.map(([r, c]) => `${r},${c}`));
    const out: { x: number; y: number; fill: string }[] = [];
    grid.forEach((row, y) => {
      for (let x = 0; x < row.length; x++) {
        let ch = row[x];
        if (ch === ".") continue;
        if (blink && ch === "G" && eye.has(`${y},${x}`)) ch = "K";
        const fill = PALETTE[ch];
        if (fill) out.push({ x, y, fill });
      }
    });
    return out;
  }, [grid, blink]);

  return (
    <svg
      width={SPRITE_W * SCALE}
      height={SPRITE_H * SCALE}
      viewBox={`0 0 ${SPRITE_W} ${SPRITE_H}`}
      shapeRendering="crispEdges"
      style={{
        imageRendering: "pixelated",
        transform: flip ? "scaleX(-1)" : "none",
        display: "block",
      }}
      aria-hidden
    >
      {rects.map((r, i) => (
        <rect key={i} x={r.x} y={r.y} width={1} height={1} fill={r.fill} />
      ))}
    </svg>
  );
}

export default function PixelCat() {
  // Temporary static render to verify the sprite looks right.
  return (
    <div style={{ position: "fixed", left: 40, bottom: 40, zIndex: 30 }}>
      <Sprite state="sit" frame={0} blink={false} flip={false} />
    </div>
  );
}
```

```tsx

  pickWanderTarget,
  pickDwellState,
  dwellDuration,
  frameForState,
} from "@/lib/catBehavior";

const SPRITE_PX = SPRITE_W * SCALE; // 64
const LERP = 0.02; // lazy glide
const STEP_MS = 220; // walk frame swap
const BLINK_MIN = 2500;
const PAW_DIST = 26;
const PAW_LIFE = 2600;
const REACTION_MS = 1800;

type Paw = { id: number; x: number; y: number };

export default function PixelCat() {

  const [state, setState] = useState<CatState>("sit");
  const [frame, setFrame] = useState(0);
  const [flip, setFlip] = useState(false);
  const [blink, setBlink] = useState(false);
  const [bubble, setBubble] = useState<string | null>(null);
  const [mounted, setMounted] = useState(false);
  const [paws, setPaws] = useState<Paw[]>([]);

  const pos = useRef({ x: 40, y: 300 });
  const target = useRef({ x: 40, y: 300 });
  const stateRef = useRef<CatState>("sit");
  const dwellUntil = useRef(0);
  const reactionUntil = useRef(0);
  const lastStep = useRef(0);
  const tick = useRef(0);
  const lastBlink = useRef(0);
  const lastPaw = useRef({ x: 40, y: 300 });
  const pawId = useRef(0);
  const size = useRef({ w: SPRITE_PX, h: SPRITE_PX });

  const setCatState = (s: CatState) => {
    if (s !== stateRef.current) {
      stateRef.current = s;
      setState(s);
    }

    const reduce =
      typeof window !== "undefined" &&
      window.matchMedia?.("(prefers-reduced-motion: reduce)").matches;

    pos.current = { x: 40, y: window.innerHeight * 0.6 };
    target.current = { ...pos.current };
    lastPaw.current = { ...pos.current };
    dwellUntil.current = Date.now() + 1500;

      const px = pos.current.x + size.current.w / 2;
      const py = pos.current.y + size.current.h - 6;
      const id = pawId.current++;

      const now = Date.now();
      const inReaction = now < reactionUntil.current;

      // Arrival check
      const dx = target.current.x - pos.current.x;
      const dy = target.current.y - pos.current.y;
      const dist = Math.hypot(dx, dy);
      const arrived = dist <= 2;

      if (reduce) {
        setCatState("sit");
      } else if (inReaction) {
        // hold reaction state set in onClick

        setCatState("walk");
        pos.current.x += dx * LERP;
        pos.current.y += dy * LERP;
        if (Math.abs(dx) > 0.5) setFlip(dx < 0);
        // walk frame cycling
        if (now - lastStep.current > STEP_MS) {
          lastStep.current = now;
          tick.current++;
          setFrame(frameForState(FRAMES.walk.length, tick.current));
        }
        // paw trail
        const pd = Math.hypot(
          pos.current.x - lastPaw.current.x,
          pos.current.y - lastPaw.current.y
        );
        if (pd > PAW_DIST) {
          lastPaw.current = { x: pos.current.x, y: pos.current.y };
          dropPaw();
        }
      } else {
        // Arrived: are we still dwelling?
        if (now >= dwellUntil.current) {
          // start a new dwell behavior OR head to a new target
          if (stateRef.current === "walk" || stateRef.current === "sit") {
            const dwell = pickDwellState();
            setCatState(dwell);
            setFrame(0);
            dwellUntil.current = now + dwellDuration(dwell);
          } else {
            // dwell finished → pick a new wander target
            target.current = pickWanderTarget(
              window.innerWidth,
              window.innerHeight,
              size.current
            );
            setCatState("walk");
            dwellUntil.current = now + 600;
          }
        } else {
          // animate multi-frame dwell states (groom)
          const frames = FRAMES[stateRef.current].length;
          if (frames > 1 && now - lastStep.current > STEP_MS * 2) {
            lastStep.current = now;
            tick.current++;
            setFrame(frameForState(frames, tick.current));
          }
        }
      }

      // Blink while idle/sit
      if (
        (stateRef.current === "idle" || stateRef.current === "sit") &&
        now - lastBlink.current > BLINK_MIN + Math.random() * 2500
      ) {
        lastBlink.current = now;
        setBlink(true);
        window.setTimeout(() => setBlink(false), 140);
      }

      if (wrapRef.current) {
        wrapRef.current.style.transform = `translate3d(${pos.current.x}px, ${pos.current.y}px, 0)`;
      }
      raf = requestAnimationFrame(loop);
    };

    raf = requestAnimationFrame(loop);
    return () => cancelAnimationFrame(raf);
  }, []);

  const onClick = () => {
    if (Date.now() < reactionUntil.current) return;
    const love = Math.random() < 0.5;
    setCatState(love ? "love" : "happy");
    setBubble(love ? "♥" : "!");
    reactionUntil.current = Date.now() + REACTION_MS;
    window.setTimeout(() => {
      setBubble(null);
      dwellUntil.current = Date.now(); // let loop pick next behavior
    }, REACTION_MS);
  };

  return (
    <>
      {/* paw trail */}
      <div
        aria-hidden
        style={{ position: "fixed", inset: 0, zIndex: 29, pointerEvents: "none" }}
      >
        {paws.map((p) => (
          <span
            key={p.id}
            style={{
              position: "absolute",
              left: p.x,
              top: p.y,
              width: 4,
              height: 4,
              borderRadius: "50%",
              background: PALETTE.D,
              animation: `pawFade ${PAW_LIFE}ms ease-out forwards`,
            }}
          />
        ))}
      </div>

      {/* cat */}
      <div
        ref={wrapRef}
        style={{
          position: "fixed",
          top: 0,
          left: 0,
          zIndex: 30,
          willChange: "transform",
          opacity: mounted ? 1 : 0,
          transition: "opacity 600ms ease",
        }}
      >
        <div
          style={{
            position: "absolute",
            bottom: "100%",
            left: "50%",
            transform: "translateX(-50%)",
            marginBottom: 2,
            fontSize: 12,
            color: PALETTE.P,
            opacity: bubble ? 1 : 0,
            transition: "opacity 150ms ease",
            pointerEvents: "none",
          }}
        >
          {bubble}
        </div>
        <div onClick={onClick} style={{ cursor: "pointer", pointerEvents: "auto" }}>
          <Sprite state={state} frame={frame} blink={blink} flip={flip} />
        </div>
      </div>
    </>
  );
}
```

## Risks, tradeoffs, open questions

1. **Hand-drawn pixel grids may need iteration.** The grids in Task 1 are a starting point; Task 5/8 visual passes exist specifically to refine them. The 16-char integrity test prevents silent grid corruption.
2. **Cat over text (decision 6).** At z-index 30 the cat draws on top of the centered column. It's constantly moving so it won't permanently obscure content, but if it ever feels distracting we can drop opacity to ~0.9 or lower z-index below interactive elements. `pointerEvents` is only `auto` on the sprite itself, so it never blocks clicks on links.
3. **Reduced motion.** Honored: the cat just sits (no wandering, no paw trail growth) when `prefers-reduced-motion: reduce`.
4. **SVG rect count.** ≤256 rects per frame, re-memoized only on frame/blink change — negligible cost. No per-frame React re-render for movement (transform via ref).
5. **Chase-tail pose** is a single compact frame (visual suggestion of spinning via the round pose + short dwell); a true rotation could be added later with a CSS `rotate` keyframe if desired — out of scope (YAGNI) unless requested.
6. **Mobile/narrow screens.** Wander target keeps the full sprite on-screen via the 8px margin clamp; on very small screens the cat simply roams a smaller area. No separate mobile logic needed.
